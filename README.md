# EuroMebel — Новогодний дом

Адвент-календарь EuroMebel, 1–31 декабря. Каждый день в 10:00 (Алматы) открывается новое окно с предложением дня и персональным промокодом.

- index.html — страница акции
- check.html — проверка и погашение кодов в салонах
- rules.html — правила акции (черновик)
- config.js — адрес бэкенда (Google Apps Script)

Предложения и промокоды хранятся только в Google Таблице и выдаются бэкендом, в этом репозитории их нет.
